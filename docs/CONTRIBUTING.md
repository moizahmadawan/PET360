# Contributing to Pet360 documentation

This repository is currently intended for public documentation and project presentation. It does not contain the application source code.

## Guidelines

1. Keep documentation consistent with the verified project status.
2. Do not claim a module is complete without evidence.
3. Preserve the original app design; refer to the Figma prototype as the design source of truth.
4. Do not add source code, secrets, credentials, private datasets, or model weights.
5. Do not upload screenshots containing personal information.
6. Label proposed architecture and API routes as proposed until verified.
7. Keep AI and animal-health disclaimers visible.

## Suggested documentation change process

- Make a focused change.
- Check Markdown links and image paths.
- Confirm no confidential material is included.
- Describe what changed and what remains unverified.
